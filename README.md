# 🎮 Unk's Bad Day

A simple text-based adventure game I built while learning Python. 🐍

The player makes choices that determine how Unk's very bad day plays out. 

## 🧠 What I Used

- 📦 Variables
- ⌨️ `input()`
- 🖨️ `print()`
- 🔀 `if / elif / else`
- 🔄 `while` loops
- 🛑 `break`
- ⏭️ `continue`
- ⏱️ `time.sleep()`

## ▶️ How to Play

Run `unks_bad_day.py` and follow the prompts. 🎮
